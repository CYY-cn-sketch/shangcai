# 创意头脑风暴方法与创意方向卡

> 说明：本文件是平台启动资料，用于演示和基础教学支持，不代表校方正式课程文件。教师可在后台替换或补充正式材料。

## 一、先从问题出发

一个可继续推进的创业方向至少要回答四个问题：谁在什么场景遇到什么问题，现有解决方式为什么仍不够好。不要先假设必须做某种产品，也不要把技术名称当成用户价值。

## 二、发散的五个入口

1. 高频摩擦：重复、耗时、容易出错或令人焦虑的任务。
2. 结果缺口：用户付出很多，但结果仍不稳定或不可衡量。
3. 资源重组：团队独有的专业、渠道、数据或场景能否组合成新服务。
4. 角色错位：使用者、决策者、付款者和受益者之间是否存在信息或激励断层。
5. 变化窗口：政策、技术、人口或消费习惯变化是否产生了新的可验证需求。

## 三、候选方向评分

每项按 1—5 分判断：问题强度、用户可触达性、团队资源匹配度、差异化、七天可验证性。总分不是最终结论；如果关键假设无法验证，应降低推荐优先级。

## 四、七天验证任务

- 访谈 5—8 名高度匹配的目标用户，记录具体事件，不只询问“你会不会用”。
- 收集现有替代方案、使用频率、花费和放弃原因。
- 制作低保真流程或人工服务原型，观察用户是否愿意完成关键动作。
- 预先定义失败信号，例如无人愿意预约、问题出现频率过低或获取一个用户的成本明显不可接受。
