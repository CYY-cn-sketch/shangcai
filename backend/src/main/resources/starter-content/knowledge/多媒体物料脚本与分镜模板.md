# 多媒体物料脚本与分镜模板

## 用途

把已确认的项目定位、BP、PPT 和路演稿转换为短视频脚本、分镜、海报文案和视觉生成提示词。本文提供制作说明模板，不调用任何媒体生成服务，也不提供未授权素材。

## 创作简报

开始前记录：

- 物料类型与用途
- 发布渠道与目标受众
- 总时长或画布尺寸
- 一个核心信息
- 一个行动提示
- 必须出现和禁止出现的内容
- 可用文字、图片、品牌与人物素材
- 素材来源、授权和隐私状态
- 使用的上游成果版本

## 30 秒视频结构

可按项目调整，默认采用：

1. 问题场景：让受众迅速理解谁遇到了什么问题。
2. 项目行动：展示核心机制或关键使用步骤。
3. 可感知成果：说明用户获得的结果，避免夸大承诺。
4. 教学或业务闭环：展示反馈、审核、验证或交付过程。
5. 收束与下一步：给出清晰行动提示。

总时长必须等于各镜头时长之和。没有真实成果素材时使用概念演示并明确标注，不能伪装成上线案例。

## 分镜字段

每个镜头包含：

- 镜头编号
- 起止时间与时长
- 场景和景别
- 画面主体与动作
- 旁白
- 屏幕字幕
- 音效或音乐需求
- 素材来源与授权状态
- 转场方式
- 制作备注

旁白、字幕和画面应表达同一核心信息，避免三条信息同时竞争注意力。

## 海报结构

- 主标题：表达一个核心价值，不堆功能。
- 副标题：补充对象、场景或结果。
- 核心视觉：说明主体、动作和关系。
- 支持信息：最多保留必要的 3—4 项。
- 行动提示：明确下一步。
- 版权与隐私说明：记录素材状态。

## 视觉 Prompt 字段

生成提示词可描述：

- 主体与角色关系
- 具体场景和动作
- 构图、镜头和视角
- 色彩、光线和质感
- 信息层级与文字留白
- 需要保持的一致性元素
- 禁止元素、隐私与版权限制

提示词不得包含真实学生姓名、账号、未授权肖像、受保护商标或未经许可的学校标识。

## 一致性检查

- 项目名称、用户、价值主张是否与上游一致
- 数字、案例和成果是否有来源
- 视频旁白、字幕、海报文案是否相互一致
- 是否出现夸大、绝对化或无法证明的承诺
- 是否误把概念画面表述为真实客户或试点
- 素材是否具备版权、肖像权和隐私授权
- 是否明确这些内容只是制作说明而非已生成文件

## MEDIA 阶段成果

输出应包含创作简报、脚本/分镜或海报结构、视觉 Prompt、素材清单、待补素材、版权与隐私风险、制作状态和来源成果版本。

阶段交接卡标记来源成果类型 MEDIA、所用上游成果类型、版本和 PENDING_STUDENT_CONFIRMATION；若发现事实冲突，应回到对应上游阶段修订。
