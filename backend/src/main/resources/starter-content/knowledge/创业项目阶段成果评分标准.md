# 创业项目阶段成果评分标准

本资料提供平台默认的阶段成果检查框架。具体权重和通过标准应以任课教师发布的正式 Rubric 为准。

## 六个检查维度

1. 创新性：问题是否真实，方案是否形成有意义的新机制或新组合，而非仅更换名称。
2. 市场洞察：目标用户、使用场景、替代方案和证据来源是否清楚。
3. 商业逻辑：付费方、价值交换、交付边界、渠道、成本与收入假设能否闭环。
4. 财务合理性：数字是否标明口径、来源、公式和敏感变量，是否避免虚构精确预测。
5. 表达呈现：BP、PPT、讲稿和答辩是否结论先行、证据对应、前后一致。
6. 团队协作：任务、负责人、验证记录、修改过程和教师反馈是否可追溯。

## 证据等级

- A：有可追溯的访谈、试点、交易、统计资料或教师确认。
- B：有明确来源的案例、公开资料或可复算过程，但尚未完成本项目验证。
- C：团队假设，已给出验证动作、成功信号和失败信号。
- D：只有结论或模板文本，没有来源、口径和验证计划。

## 通过、退回与优秀

- 通过：阶段目标完整，关键结论至少达到 B 或 C 级，并有明确下一步验证任务。
- 退回：目标用户、核心问题、付费闭环或主要证据缺失；前后阶段明显冲突；把假设写成事实。
- 优秀候选：证据充分、边界清楚、阶段间交接完整，并能说明失败条件和复盘结果。

AI 只能按上述维度给出预检查建议，不能替代教师作出最终评分、通过或优秀认定。
