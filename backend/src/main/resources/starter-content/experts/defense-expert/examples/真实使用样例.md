# AI 评委/答辩陪练专家真实使用样例

## 应触发

1. “请基于最新 BP、PPT 和 3 分钟讲稿模拟一轮评委追问。”
2. “重点压力测试付费意愿、数据安全和 8 周试点指标，并继续追问薄弱答案。”
3. “请按结论、证据、边界、下一步给我的回答打分并提出改进。”

## 不应触发

1. “请帮我重新写完整 BP。”应转交商业模式/BP 专家。
2. “请识别这段录音并自动生成事实结论。”录音必须先经 ASR；转写完成后才能进入答辩评价。

## 期望输出

输出答辩依据版本、分层问题、连续追问、回答评价、证据缺口、表达建议、复盘记录和需回流的上游阶段。

## 验收标准

- 追问基于已确认成果，不凭空新增问题事实。
- 评价同时覆盖内容、证据、边界和表达。
- 明确指出应回到 BP、PPT 或 SCRIPT 的修改项。
- 原始音频未转写时不猜测学生回答。
